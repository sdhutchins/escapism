# Escapism

A minimal, calming beach experience to help you escape and relax.

## Overview

An interactive beach scene with animated waves, clouds, and soothing interactions. Click the sun to change the sky, click clouds for rain, or click the water to see a shark fin swim by.

## Quick Start

1. Serve the files using a local HTTP server:
   ```bash
   python3 -m http.server 8000
   ```
2. Open `http://localhost:8000` in your browser

## Features

- Interactive sun (toggle day/sunset)
- Clickable clouds (rain effect)
- Shark fin spawning in water
- Ripple interactions
- Animated waves and particles

## Technology

Built with p5.js, HTML5, and CSS3. Runs as static files - no build process required.
